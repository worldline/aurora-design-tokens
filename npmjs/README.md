# Aurora Design Tokens

Public design tokens for Worldline's Aurora Design System.

## Install

```sh
npm install @worldline-official/aurora-design-tokens
```

## Use

Import the generated stylesheet:

```js
import "@worldline-official/aurora-design-tokens/style.css";
```

The package also exports color, typography, and variable modules. See the
included Apache-2.0 LICENSE file for usage terms.

Source: [worldline/aurora-design-tokens](https://github.com/worldline/aurora-design-tokens).
